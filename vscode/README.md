# Bahasa Pemrograman Indonesia untuk VS Code

Dukungan VS Code untuk [Bahasa Pemrograman Indonesia](https://github.com/sofanaja44/Bahasa-Indonesia), bahasa pemrograman dengan kata kunci bahasa Indonesia yang terbaca seperti bercerita:

```
buat nama adalah tanya "Siapa namamu? "
jika nama tidak sama dengan "", maka tampilkan format"Halo, {nama}!"

ulangi 3 kali:
    tampilkan "Hore!"
```

## Fitur

- **Pewarnaan kode** untuk berkas `.id`, termasuk frasa seperti `lebih dari atau sama dengan`, `jam sekarang`, dan `angka acak`, serta kalimat perintah seperti `ubah ... menjadi ...` dan `tambahkan ... ke ...`.
- **Potongan kode (snippet)**: ketik `jika`, `selama`, `ulangi`, `untuk setiap`, `fungsi`, `kelas`, `pilih`, `coba`, `tanya`, lalu tekan Tab.
- **Jorokan otomatis**: baris setelah `:`, `maka`, atau `lakukan` langsung menjorok 4 spasi.
- **Tombol ▶ Jalankan** di pojok kanan atas editor (atau `Ctrl+F5`): program dijalankan di terminal.
- Komentar dengan `Ctrl+/`, dan blok bisa dilipat.

## Menjalankan program

Tombol ▶ menjalankan perintah `indonesia namaberkas.id` di terminal. Pasang dulu salah satu:

- **Aplikasi `indonesia`** dari [halaman Releases](https://github.com/sofanaja44/Bahasa-Indonesia/releases), lalu letakkan di folder yang ada di PATH; atau
- **Kode sumbernya** (butuh Python 3.11+), lalu atur **Bahasa Indonesia: Perintah** di Settings menjadi misalnya `python C:/Bahasa-Indonesia/indonesia.py`.

Tanpa memasang apa pun, program juga bisa dicoba di [editor web](https://sofanaja44.github.io/Bahasa-Indonesia/).
